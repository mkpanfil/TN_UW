This is GitHub repository for the *Tensor networks methods for low dimensional systems* course taught at the University of Warsaw.

The slides for the first two lectures (on quantum many-body physics and spin chains) are in the `Lectures/` folder.

For the introduction to Tensor Networks and MPS, we follow recent [Lecture Notes](https://arxiv.org/abs/2606.24803v1) by Gregoire Misguich.
